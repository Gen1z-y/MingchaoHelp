# 鸣潮助手 · 声骸配装

Windows 本地工具。当前支持简体中文声骸详情识别、逐件核对入库和五件搭配搜索。

## 启动

双击项目目录里的 MingchaoHelp EXE 即可启动。单文件版内置 Python 和中文 OCR 模型。库存位于 EXE 同目录的 `.local`，与同目录源码版共用。

### 从源码启动

在项目目录用 Python 3.11 运行。已有依赖时可直接执行第二行。OCR 第一次使用时会下载模型到项目的 `.ocr-models`，之后在本机识别。

```powershell
python -m pip install -r requirements.txt
python app.py
```

### 构建单文件 EXE

在 Windows 的 Python 3.11 虚拟环境中安装构建依赖。生成的 EXE 位于 `.pack\dist`，放到项目根目录后可直接使用已有库存。

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --distpath .pack\dist --workpath .pack\work MingchaoHelp.spec
```

`.pack` 存放打包环境、中间产物和测试版。日常使用根目录的 EXE 和同目录的 `.local` 库存数据。

## 采集与配装

### 自动扫描

在游戏里打开 **背包 → 声骸**，把列表右缘的滑块拉到顶部并选中一件声骸。回到 MingchaoHelp 点击「自动扫描」，在 Windows 授权窗口中确认，然后切回游戏。扫描进程会逐件点选并等详情稳定后截图，再拖动列表右缘的滑块，确认上下画面有重叠后继续采集。主界面和 OCR 以原权限运行。

自动扫描使用**等级从高到低排序**的背包。只点选右下角标有 **+25** 的卡片，首次确认遇到低等级或堆叠声骸时结束。等级未读清的卡片会计入统计。背包筛选只选一套合鸣时，助手会读取背包下方的筛选名称，补全整轮扫描里详情没显示的套装；筛选和详情冲突时会暂停。穿戴角色从详情读取，也会用卡片左上角头像判断穿戴状态。扫描期间保持游戏在前台。按 Esc、切出游戏或点击「停止自动扫描」均可停止。拖动后会比对多个区域，并在位置不明时换距离重试。续扫前请把背包滚回顶部并保留原排序和筛选。

自动扫描在内存中识别截图，库存保存声骸词条等识别结果。在「声骸库存」可按角色或套装查找，输入关键词或直接从下拉框选择。点击「按角色卸下」可解除该角色的本地穿戴绑定，声骸留在库存中并可参与其他角色的配装。点击「按套装清除」并确认后会删除该套装的本地记录。

### 手动采集

1. 点击「导入截图」可批量导入声骸详情截图。读取到 +25 时自动入库。
2. 手动采集的截图仅在内存中识别，库存保存词条、已识别字段和错误信息。旧版待处理截图首次启动时会自动识别后移除，旧版程序生成的预览也会移除。导入的原图不会被处理或删除。在库存勾选「只看待核对」可定位识别异常，选择声骸后用「编辑」修正。整条识别失败或等级未读清的条目可在「扫描异常」查看。
3. 在「计算搭配」选择角色、合鸣套装并按需调整面板目标。角色预设优先采用库洛攻略站默认展示的简体中文攻略，包括声骸主词条、副词条优先级、合鸣套装和等级 90 的推荐面板。攻略推荐生命、防御、治疗效果或技能伤害加成时，界面会显示对应的目标输入框。攻略使用「大于」时，程序按下一显示单位作为最低值，例如「大于 20%」按 20.1% 判断。预设随 EXE 离线提供，界面上的来源按钮可打开对应攻略。角色缺少库洛攻略时使用内置的社区攻略。点击「恢复官方推荐」可重置目标和套装。输入其他角色名也可自定义目标。装备声骸后的面板会计入已收录角色的等级 90 基础属性，以及技能树属性节点全部点亮后的常驻加成。选了武器时再叠加武器的基础和常驻属性。结果页列出已计入的技能树加成。达到目标的组合排在前面，其余按目标缺口排列，再按推荐词条或循环伤害排序。同时设置暴击和暴击伤害目标时，未达标的暴击缺口按 1.15 倍计算。结果会显示主副词条、各项目标的达标情况、首位和已建模的合鸣。

库洛攻略中的主方案与备选方案分别记录五个主词条槽位。计算时按整套方案匹配 COST、主词条类型和件数，有推荐首位时也会校验其主词条。库存缺少合适声骸时，结果区会提示缺少的主词条、首位或套装。维里奈的隐世回光方案需要两件 COST 1 攻击%，每件所带的固定生命仍计入面板。

程序启动后会在后台检查库洛攻略站的角色索引，运行中通常每六小时检查一次。新角色发布完整的简体中文攻略后，程序会将面板目标、推荐套装、首位和五个主词条槽位加入角色列表，并补充已能获取的角色基础面板和技能树常驻属性。已下载的攻略保存在 `.local/kuro-guides`，下次离线启动也可使用。网络不通或新角色的方案尚未齐全时，程序会在运行中继续重试。

计算搭配时，选中武器即可按该武器的满级一阶面板计算。武器选项按角色武器类型筛选，每个角色会记住上次计算使用的武器。已知角色使用 90 级基础属性，武器的基础攻击、副属性和一阶常驻属性计入估算，战斗触发和队伍增益留待实战判断。不指定武器时沿用原有估算。目标区显示角色已启用的目标，可用「添加目标」补充，清空后再次计算可隐藏该项。武器和角色基础数值来自 [Encore.moe](https://encore.moe/)。

库存和扫描进度在 `.local`。目前计入衔梦照世之心、轻云出月给自身的共鸣效率，以及天演溯心和解形煞的首位面板效果。其余套装只计词条。当前伤害指数适合在相同输入下比较搭配，角色技能时序、声骸主动伤害和配队专属效果尚未建模。

「计算搭配」的角色按首次实装时间倒序排列。选择角色后，默认使用库洛攻略站的推荐套装和首位声骸。五件套要求五种不同名声骸，混合套装按攻略列出的件数计算。下拉框支持输入名称的一部分，点箭头或按 ↓ 查看匹配项，只有一个匹配项时可按回车选中。
